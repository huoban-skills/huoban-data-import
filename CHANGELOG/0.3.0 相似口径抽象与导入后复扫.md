# 0.3.0 相似口径抽象与导入后复扫

> 2026-09-04

首次实战收尾后复查发现六个"其实是同一个"的关联记录被当新数据建了进去：修饰语一边写在名称一边写在规格、名称有错字、包装写法折算后相等。相似判定口径重做，并在流程末尾加一道复扫。

## 摘要

1. 优化: 相似判定改成与业务无关的逐段口径——去括号后相同、数字折算相等都算等价，不再靠"第一段相同"的特例
2. 新增: 疑似匹配文件用 `--aux` 按场景并排展示对照列（厂家、地址），只给人看，不参与判定
3. 优化: 待导入不只导主键——`--carry` 支持异名映射与同名全带，能映射到关联表的列一律带上
4. 新增: 导入后复扫脚本 `resweep.py`——本批新建的关联表记录与系统其它记录按同一口径再比一遍，清单清空才收尾
5. 新增: 改指脚本 `relink.py`——按备份与裁决逐条改关联字段并落记录，批量更新命令因整条校验必填不适用
6. 新增: 执行规则——列映射留档、临时取消必填的固定动作、待判记录先删后补、改动范围只限本批
7. 新增: 回传解析规则——留空按不是同一个、备注疑问带数据答复、判定与对照列矛盾的单独复核

---

## 详情

### 1. 优化: 相似判定口径

实现在 `_common.keys_similar`。两侧主键逐段比对，每段先归一化（全角半角、空白、大小写、×/x 统一成 *）。一段算等价：归一化后相同；或去掉括号修饰语后相同（「产品A（无糖）」与「产品A」）；或数字等价——数字序列相同，或首个数字相同且其余数字乘积相同（「2mg*28s」与「2mg*7片*4板」）。一段算相似：去括号后一方包含另一方，或相似度过 `--cutoff`。多段主键要每段至少相似且至少一段等价；单段主键只看相似度。判定不看厂家、状态这类业务字段。

改前 → 改后：

| 改前 | 改后 |
| -- | -- |
| 整串相似度过 0.75，或第一段完全相同 | 逐段比对；等价段不受阈值影响；多段要求至少一段等价 |
| 「产品A（无糖）｜2.5g*21d」对「产品A｜2.5g*21袋（无糖）」判完全无 | 名称段去括号后等价、规格段数字等价，判相似待确认 |

### 2. 新增: 对照列

`render_match_report.py --aux 源列=关联表字段,...`：疑似匹配结论 sheet 在相似度后并排放「源文件·X」「系统·X」，明细 sheet 在疑似列后放「系统·X」。放什么由场景定，脚本不预设。

### 3. 优化: 待导入带全列

`--carry` 接受 `源列=关联表字段`（异名映射）和 `all`（自动带与关联表同名的非主键列）。文档明确：待导入不是只导主键，漏带的字段导完要回头补更新。

### 4. 新增: 导入后复扫

`resweep.py --snapshot 快照 --key 主键 --mine-col/--mine 或 --since-col/--since 圈本批 --aux 对照列`：本批记录与其余记录按 `keys_similar` 比对，输出「〈表〉-复扫.xlsx」（两侧主键、两侧 item_id、相似度、对照列、确认结果下拉）。流程与模板 2.4 加"复扫本批新建的关联表记录"一步，判同一个的改指后删本批那条。

### 5. 新增: 改指脚本

`relink.py --table --field --links 备份 --map 映射 --out 记录 [--verify --field-id]`：只处理备份里列出的本批记录，逐条 `update-item` dry-run 后 `--yes`，记录追加写；`--verify` 全表回读确认没有记录再指向旧 id。`update-items-by-ids` 会整条校验必填，其它必填为空的行被拒，故不用。

### 6. 新增: 执行规则

- 每次 prepare 把 `auto_matches` 留在执行记录，源文件几列就对上几列，小批量补导同样。
- 临时取消必填是一个动作：读当前必填清单 → 取消 → 导 → 不论成败立即恢复 → 回读核对；每次重新读清单。
- 待判记录先删后补：只删本批建的，删前备份指向它们的记录与关联字段进 `源文件/`，回传后判同一个的改指系统记录、判不是的按原值重建再改指。
- 改动范围只限本批导入建的数据，分几天导的算一批；其他人建的只列不动；条数差异先按创建人拆。

### 7. 新增: 回传解析规则

确认结果留空按「不是同一个」；备注列的疑问把两侧数据摆出来答复后再动；判定与对照列明显矛盾（判同一个但厂家不同）单独列出复核，不照单执行。
