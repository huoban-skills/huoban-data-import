# 0.1.0 初版

- 两阶段流程：阶段一定拆分与数据主键并停下让用户确认，阶段二三层体检、导入方案、执行、交付待处理清单。
- 导入方式固定 create；写入只走 `hac table +import-file`，本地解析仅用于体检和生成清洗文件。
- 脚本：`get_source_profile.py` 源文件体检与判重，`render_match_report.py` 三档匹配比对并生成待导入/疑似匹配 Excel。
- 模板：导入方案四段（本次导入总览、系统改动、补索引、执行次序），待处理清单面向业务人员。
- 主键判定收录平台约束：自增编号、文本计算字段服务端拦截导入写入，需临时文本字段承载编号。
