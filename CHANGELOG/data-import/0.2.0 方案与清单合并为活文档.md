# 0.2.0 方案与清单合并为活文档

- 待处理清单并入导入方案，一份六节活文档（体检概览、待客户处理、系统改动、补索引、导入总览、执行次序）贯穿导入全程；首版交客户时第五、六节标"待回传后确定"，第二节清空且全量核对通过即收尾。
- 流程调序：清单先于方案交客户改为方案首版即交客户，回传复检后填定条数，方案一次出对。
- 阶段一匹配机制改按目标表分块；主键字段用目标表原名，关联字段不嵌套展开。
- 疑似匹配 Excel 双 sheet：结论 sheet 下拉三选一，明细 sheet 抽源表行对照；注入的常量维度展示时剥掉。
- 关联表数据改 `list-items` 分页拉取（`+export` 是写风险命令）；新增 `--const`、`--drop-blank-keys`；`write_xlsx_sheets` 支持多 sheet 与下拉列。
- 交付目录定型：根放方案 md，`待导入/`、`待确认/`、`源文件/` 三层。
- 主键判定收录：编号字段是自增编号/文本计算时服务端拦截写入，需临时文本字段承载。
