# 0.4.0 相似口径抽象与导入后复扫

- 相似判定口径抽象到 `_common.keys_similar`，与业务字段无关：主键逐段比对，一段等价 = 归一化相同 / 去括号修饰语后相同 / 数字等价（序列相同或首数相同且其余乘积相同）；多段主键要求每段相似且至少一段等价，单段主键看相似度。取消"第一段相同"的特例。
- `render_match_report.py`：`--aux 源列=关联表字段` 在疑似匹配文件两侧并排展示对照列（厂家、地址这类由场景定，不参与判定）；`--carry` 支持 `源列=关联表字段` 与 `all`（同名列），待导入必须带全能映射的列，不只导主键。
- 新增 `resweep.py`：导入后把本批新建的关联表记录与系统其它记录按同一口径复扫，出复扫清单；流程里加"复扫本批新建"一步，清单清空才收尾。
- 新增 `relink.py`：按备份与映射逐条 `update-item` 改指关联字段并落记录，可回读校验；`update-items-by-ids` 整条校验必填不适用。
- 执行规则补入：prepare 后 `auto_matches` 必须留档且列数对齐；临时取消必填是"读→取消→导→恢复→回读"的固定动作；待判记录先删后补的备份与回填流程；改动范围只限本批（多日算一批），其他人建的只列不动，条数差异先按创建人拆。
- 回传解析规则：留空按不是同一个；备注疑问带数据答复后再动；判定与对照列矛盾的单独复核。
