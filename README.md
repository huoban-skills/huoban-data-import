# huoban-data-import

把 Excel/CSV 批量导入伙伴云已有表，并让每一行正确关联上系统里的现有数据：先定数据主键、量出匹配率，把对不上的部分整理成待确认文件交人裁决，确认后再走官方导入通道分批写入、逐批回读核对。

## 解决什么问题

批量导入的难点不是把数据写进去，而是关联字段能不能指向正确的那条现有数据。名称差两个字、同名不同角色、基础数据缺失，都会导致关联失败甚至产生重复脏数据。本 skill 把这些问题全部前置：导入之前量化匹配现状、交人确认，导入之后核对条数，不让脏数据落库。

## 怎么用

对 AI 说"把这份 Excel 导入某某工作区"即可触发。流程分两阶段，两个停点都会主动停下等确认：

```
摸现状 → 拆分表+匹配机制表 →【确认拆分与主键】→ 三层评估 → 导入方案首版
→【确认待确认内容】→ 系统改动/补索引/补关联数据 → 小样本试导 → 分批导入+回读 → 复扫 → 收尾
```

- **阶段一**产出两张表：源文件拆成几批导进哪些表、每张表拿什么当数据主键。
- **阶段二**产出一份《导入方案》活文档（评估结果 + 执行清单两章）和若干 Excel：
  - `待导入/`：系统里没有的基础数据，核对后可直接导入；
  - `待确认/`：与系统名称相似但不一致的，明细 sheet 对照源表行，结论 sheet 下拉判断"是不是同一个"。
- 确认结果回来后复检、填定条数，再执行导入。方案是唯一事实源，全程随进展更新。

## 边界

- 只新增数据（create），更新或覆盖已有数据不在本 skill 范围。
- 写入只走伙伴云服务端导入通道（`hac table +import-file`），本地解析仅用于评估和生成清洗文件。
- 不修改、不删除系统已有数据；清理、改指、删除只限本批导入建的记录。发现的其它问题（重复、误建）进方案待确认，由人决定处理。

## 目录

| 位置 | 内容 |
| -- | -- |
| `SKILL.md` | 主流程：两阶段编排、依赖、确认门 |
| `references/keys-and-split.md` | 数据主键怎么定、源文件怎么拆 |
| `references/assessment.md` | 三层评估（源表层/配置层/数据层）逐项判定 |
| `references/execution.md` | 导入编排、基线快照、小样本、回读核对 |
| `assets/import-plan-template.md` | 《导入方案》活文档模板 |
| `scripts/get_source_profile.py` | 源文件体检：列清单、空值率、按主键判重 |
| `scripts/render_match_report.py` | 源数据与系统关联表比对，产出三档匹配率和待导入/疑似匹配 Excel |
| `scripts/resweep.py` | 导入后复扫：本批新建的关联表记录与系统其它记录再比一遍 |
| `scripts/relink.py` | 按裁决把本批导入记录的关联字段逐条改指，落记录文件 |
| `CHANGELOG/` | 版本记录 |

评估与复扫脚本只读本地文件；`relink.py` 通过 hac 逐条写关联字段，只作用于本批导入的记录。
