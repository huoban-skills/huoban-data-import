# 导入方案模板

一份活文档贯穿导入全程，两章：「评估结果」列现状与待确认事项，「执行清单」记执行动作与回读。找谁确认（客户、同事或自己拍板）由用户定。评估后首次产出时导入总览标"待确认后填定"，确认结果回来复检后填定数字，执行中持续更新，待确认清空且全量核对通过即收尾。只写结论和动作，不写推导过程；每个小节第一句先点明对象（哪张表、哪个文件、哪个字段），再说要做什么；填写时删掉所有括号内的说明文字。

# 一、评估结果

## 1.1 概览

| 关联项 | 能对上 | 相似需确认 | 系统里没有 |
| -- | -- | -- | -- |
| 〈关联项〉 | X%（N 行） | X%（N 行） | X%（N 行） |

当前的拦路问题，一句一个：

1. 〈闸门问题，说清影响多少行、需要确认什么〉

## 1.2 待确认内容

确认结果回来复检后本节逐条勾销；执行中新发现的问题也追加在这里。

### 1.2.1 重复数据

源文件〈文件名〉内部，按〈目标表〉的主键〈主键说明〉判断，以下 N 组重复，需确认保留哪一条。已在 `〈文件名〉-待处理.xlsx` 中标黄。

| 行号 | 内容 | 冲突点 |
| -- | -- | -- |
| 12, 87 | 〈值〉 | 两行的〈某列〉不同 |

### 1.2.2 名称对不上的

源文件的〈哪几列〉与系统〈哪几张关联表〉里的名称相似但不完全一致的，整理在「待确认」文件夹。明细 sheet 对照源表行（疑似匹配列标黄），结论 sheet 逐条下拉选择：

| 文件 | 条数 | 典型例子 |
| -- | -- | -- |
| 〈关联表〉-疑似匹配.xlsx | N 个名称（M 行） | 〈差异模式一句话〉 |

### 1.2.3 需要新建的基础数据

源文件里有、系统〈哪几张关联表〉里完全没有的数据，整理在「待导入」文件夹，请核对，不需要建的删掉行：

| 文件 | 条数 | 说明 |
| -- | -- | -- |
| 〈关联表〉-待导入.xlsx | N | 〈说明〉 |

# 二、执行清单

## 2.1 导入总览（确认后复检填定）

按执行次序列出每一张会新增数据的表，包括关联表补数和目标表。

| 序 | 表 | 导入文件 | 导入前条数 | 本次导入条数 | 导入后应有条数 | 说明 |
| -- | -- | -- | -- | -- | -- | -- |
| 1 | 〈关联表〉 | 〈关联表〉-待导入.xlsx | K | N | K + N | 系统里没有的基础数据，已确认 |
| 2 | 〈目标表〉 | 〈目标表〉-可导入.xlsx | P | M | P + M | 主键无重复、关联全部可匹配的行 |

未列入本表的关联表，导入全程条数不应变化；变多说明导入过程在关联表里建了新数据，停下核查。

没进可导入文件的行放在 `〈目标表〉-待处理.xlsx`，回到 1.2 待确认，复检通过后补一轮导入。

## 2.2 系统改动

按表分块，供确认；改完打勾。

### 〈表名〉

| 字段 | 说明 | 是否需要确认 | 状态 |
| -- | -- | -- | -- |
| 〈字段名〉 | 源数据这一列有空值，需取消必填。导入后是否恢复请确认 | 是 | ☐ |
| 〈字段名〉 | 新增快照字段，留存导入时的〈内容〉，避免基础数据改动影响历史记录 | 是 | ☐ |

## 2.3 补索引

| 表 | 索引字段 | 字段类型 | 取值规则 | 后续维护 | 状态 |
| -- | -- | -- | -- | -- | -- |
| 〈关联表〉 | 〈字段名〉 | calculation | 〈字段A〉｜〈字段B〉 | 自动维护 | ☐ |
| 〈关联表〉 | 〈字段名〉 | text | 〈拼接规则〉 | 需补自动化，否则新增数据无索引 | ☐ |

源文件侧同步加索引列，归一化规则：去首尾空格、全角转半角、统一括号形态。两侧规则必须一致。

## 2.4 执行次序

| 序 | 动作 | 验证点 | 回读记录 |
| -- | -- | -- | -- |
| 1 | 完成系统改动（2.2） | 字段已建、必填已取消 | |
| 2 | 回填关联表索引值（2.3） | 索引字段无空值 | |
| 3 | 按导入总览导入关联表补数 | 实际条数 = 总览导入后应有条数 | |
| 4 | 小样本导入 10 到 20 条 | 条数增量正确、抽查关联指向正确、关联表条数未变 | |
| 5 | 分批导入剩余数据 | 每批同上三项回读 | |
| 6 | 全量核对 | 每张表实际条数 = 总览导入后应有条数 | |
| 7 | 复扫本批新建的关联表记录 | 复扫清单裁决完、改指与删除回读通过 | |

小样本导入的数据不删除，直接作为正式数据第一批。任一批次回读对不上立即停下，问题记回 1.2，不继续后续批次。
